A robot apologizes for vacuuming up a grandmother's handwritten recipe card and learns to photograph paper-thin things before cleaning. The program writes a two-line confession to `/output/entry.txt`: one sentence owning the specific mistake, one naming the lesson and the fix that follows from it.

## Run it

```sh
node main.ts
```
